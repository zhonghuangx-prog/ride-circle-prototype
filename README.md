# Ride Circle Prototype

Mobile-first cycling app prototype built with React, Vite, Tailwind CSS, and AMap.

## Local development

```bash
npm install
npm run dev
```

## Environment variables

Create a `.env` file with:

```bash
VITE_AMAP_API_KEY=your_amap_web_js_api_key
VITE_AMAP_SECURITY_KEY=your_amap_security_js_code
```

## GitHub Pages

This repository includes a GitHub Actions workflow that builds the app and deploys it to GitHub Pages on every push to `main`.
